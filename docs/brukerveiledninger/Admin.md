# Brukerveiledning for administratorer

For å ha tilgang til disse funksjonene må brukeren din ha admin rolle

## Navigering til admin panelet

1. Naviger til "Dashbordet" i navigasjonsmenyen og Trykk på "Admin" i menyen nedenfor.
   ![Utlogging bilde](/docs/images/Screenshot4.png)

## Sette pris på spillere

Trykk inn på "Sett priser" på admin panelet.

1. Velg spiller i dropdown-menyen
2. Skriv inn prisen du vil sette på spilleren
3. Trykk på "Sett pris" for å sette prisen på spilleren

   ![Utlogging bilde](/docs/images/Screenshot5.png)

## Se og slette brukere

Trykk inn på "Brukere" på admin panelet.

1. Her kan du se alle brukerene i systemet
2. Trykk på søppelspannet til høyre for brukeren for å slette den

   ![Utlogging bilde](/docs/images/Screenshot6.png)
