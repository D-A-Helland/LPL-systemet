# Kompetansemål

## Utvikling

Modellere og opprette databaser for informasjonsflyt i systemer
- Vi har fokusert på dette kompetansemålet ved å strukturere og normalisere en database med PostgreSQL og ved å bruke prisma for å håndtere data lettere.


Vurdere fordeler og ulemper ved ulike programmeringsspråk og velge og anvende relevante programmeringsspråk og algoritmer i eget arbeid
- Hvordan vi fokuserte på dette kompetansemålet står det om i "Teknisk dokumentasjon"

## Driftstøtte

Planlegge og dokumentere arbeidsprosesser og IT-løsninger
- Vi har fokusert på dette ved å sette av tid til å spesifikt planlegge og dokumentere løsningen vår. 
- Stort sett ble første dagen satt av til planlegging og siste dagen ble stort sett satt av til dokumentasjon.

## Brukerstøtte

Beskrive og bruke rammeverk for kvalitetssikring av IT-drift
- Vi har fokusert på dette ved å bruke Nuxt som hovedrammeverk, som gir en strukturert måte å utvikle applikasjonen på.
- Vi har også brukt ESLint for å sikre god kodekvalitet.

Bruke og administrere samhandlingsverktøy som effektiviserer samarbeid og deling av informasjon
- Vi har fokusert på dette ved å bruke git til å dele kode og samarbeide i prosjektet.
- I utgangspunktet skulle dette gjøre det lettere å holde oversikt over endringer og jobbe effektivt sammen.
